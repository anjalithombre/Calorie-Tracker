# 🥗 Calorie Tracker Web Application

A simple and efficient web application to track daily calorie intake, monitor diet, and maintain a healthy lifestyle.

## 🚀 Features

- 🔐 User Authentication (Login & Signup)
- 🍽️ Add, edit, and delete meals
- 📊 Daily calorie tracking dashboard
- 📅 Track calories by date
- 🔎 Search food items
- 📱 Responsive design for mobile and desktop
- 💾 Data stored securely

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript / React (update if needed)
- **Backend:** Node.js / Express (or your tech)
- **Database:** MongoDB / MySQL / Firebase
- **Other Tools:** Bootstrap / Tailwind CSS

🧠 How It Works
Users can register and log in
Add meals with calorie values
The system calculates total daily calories
Users can view history and track progress
